# Shoeb AI

A personal AI chat app for Android.

- **Download the APK:** [ShoebAI.apk](https://github.com/shoebkan4u/hark-ai-chat-app/raw/main/ShoebAI.apk) (also at https://shoebkan4u.github.io/hark-ai-chat-app/ShoebAI.apk; the old HarkAI.apk links get the same file)
- **Web version:** https://shoebkan4u.github.io/hark-ai-chat-app/

This repository holds only the built web app served by GitHub Pages. It contains no keys or personal data. Add your own keys in the app (Settings → Keys) or import your encrypted Hark bundle (Settings → Import from Hark).

To install: download `ShoebAI.apk` on your phone, open it, and allow installs from your browser when Android asks.
